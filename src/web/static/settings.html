Shared defaults used by Send and Receive
Recommended baseline for most 2-PC setups: Fountain + Balanced + 2 bpc, with low preview quality on the receiver. Switch to Speed only on a dedicated 120/144/240Hz HDMI path.
Transfer defaults
Default device
? Receiver-side capture source. In a 2-PC setup, this should be the HDMI capture card connected to the sender PC.
Applied when opening Receive
Default profile
? Geometry and target framerate preset. Balanced is the default for broad compatibility. Speed only helps when the sender HDMI path itself is running above 60 Hz.
Shared by Send and Receive
Default mode
? Fountain is the best default for real transfers. Auto helps during bring-up on the receiver when you do not know the sender protocol yet. Sequential is mostly a debug path.
Receiver uses Auto too; sender falls back to Fountain
Default encoding
? Bits per color channel used to encode payload data. 2 bpc is the best default. The sender preflight can automatically step down if the HDMI path cannot keep the signal clean.
Shared by Send and Receive
Preview quality
? Receiver preview JPEG quality. This does not change the transfer itself. Lower values are better for stability on weaker receiver PCs.
Receiver only
Auto device scan
? Refreshes the capture-device list automatically when opening Receive. Keep this enabled unless your receiver PC has unstable drivers and you want to rely on cached devices only.
Receiver only
Idle preview
? Shows the live capture view before a transfer starts. Useful during setup. Turn it off if the receiver PC is weak and you want to minimize background load.
