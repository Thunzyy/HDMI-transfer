    3. Create `src/hdmi_exfil/constants.json` containing ALL shared encoding parameters:
    ```json

      "width": 1920,
      "height": 1080,
      "block_size": 8,
      "seq_magic": 55930,

    }
    ```

    Note: 55930 = 0xDA7A, 61632 = 0xF0C0. Use decimal in JSON for cross-language compatibility.

    4. Create `src/hdmi_exfil/config.py` that:
       - Uses `importlib.resources.files("hdmi_exfil").joinpath("constants.json")` to load constants.json

       - Frame types are NOT in constants.json (they are protocol-specific constants defined in config.py directly)
       - SEQ_HEADER_FMT = '>HBIIH', computed sizes derived from struct.calcsize
       - BYTES_PER_FRAME = (BITS_PER_FRAME // 8) - HEADER_SIZE (same formula as common.py)
       - Values MUST match common.py exactly: BYTES_PER_FRAME = 12133

       - Package discovery: where = ["src"]
       - Package data: hdmi_exfil = ["constants.json"]
       - Pytest config: testpaths = ["tests"], addopts = ["--strict-markers", "-v", "--import-mode=importlib"], markers as currently defined
       - Do NOT delete pytest.ini yet (tests still use old imports; will be removed in 03-07)
