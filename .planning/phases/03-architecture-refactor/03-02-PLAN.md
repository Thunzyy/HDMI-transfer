       - When offset_x=0, offset_y=0, scale_x=1.0, scale_y=1.0, the output MUST match receiver.py's sample_frame exactly for the same input frame.
       - Handle edge case: resize frame to expected dimensions if shape doesn't match `rows * block_size` x `cols * block_size`.
