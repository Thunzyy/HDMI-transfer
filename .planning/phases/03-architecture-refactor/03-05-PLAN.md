       - `get_capture_backend() -> int`: Returns cv2.CAP_DSHOW (win32), cv2.CAP_V4L2 (linux), cv2.CAP_AVFOUNDATION (darwin), cv2.CAP_ANY (other). Uses sys.platform.
       - `class CaptureSource`:
         - `__init__(self, source: int | str, width=1920, height=1080, fps=60)`:
           - Try `cv2.VideoCapture(source, get_capture_backend())`
           - If not opened, fallback to `cv2.VideoCapture(source, cv2.CAP_ANY)`
           - If still not opened, raise `RuntimeError(f"Could not open video source {source}")`
           - Set CAP_PROP_FRAME_WIDTH, CAP_PROP_FRAME_HEIGHT, CAP_PROP_FPS
           - Store actual values via cap.get()
         - Properties: `actual_width`, `actual_height`, `actual_fps` (read from cap.get)
         - `read(self)`: Returns cap.read()
         - `release(self)`: Calls cap.release()
         - Context manager: `__enter__` returns self, `__exit__` calls release
       - Replace the hardcoded `cv2.CAP_DSHOW` in receiver.py and receiver_fountain.py

    2. Create `src/hdmi_exfil/display/renderer.py`:
       - `class FrameRenderer`:
         - `__init__(self, window_name="HDMI Exfil", x_offset=0, y_offset=0)`:
           - Creates named window with cv2.WINDOW_NORMAL
           - Moves to (x_offset, y_offset)
           - Sets fullscreen property
         - `show(self, frame, delay_ms=1) -> int`: Calls cv2.imshow + cv2.waitKey, returns key pressed
         - `destroy(self)`: Calls cv2.destroyAllWindows
         - Context manager: __enter__/__exit__
       - This is a thin wrapper. Phase 4 will replace internals with pygame-ce.

    3. Create `src/hdmi_exfil/display/monitors.py`:
       - `get_monitors() -> list[dict]`:
         - Uses `screeninfo.get_monitors()` to get monitor list
         - Returns list of dicts with keys: left, top, right, bottom, width, height (matching sender.py's format)
         - Wraps in try/except: on ImportError (screeninfo not installed) or any RuntimeError, falls back to a single default monitor dict: {"left": 0, "top": 0, "right": 1920, "bottom": 1080, "width": 1920, "height": 1080}
       - This replaces the Windows-only ctypes.windll.user32.EnumDisplayMonitors in sender.py
