    ```
    from sender import encode_frame              -> Use SequentialProtocol().encode_frame or create module-level helper

    from sender import encode_end_frame          -> SequentialProtocol().encode_end_frame

    from receiver import sample_frame            -> from hdmi_exfil.capture.sampler import sample_frame

    from receiver import decode_frame_full       -> SequentialProtocol().decode_frame
    from receiver import parse_start_metadata    -> from hdmi_exfil.file_handling.metadata import parse_start_metadata

    from common import *                         -> from hdmi_exfil.config import WIDTH, HEIGHT, ... (explicit imports)
    from receiver_fountain import PRNG           -> from hdmi_exfil.prng import PRNG
    from receiver_fountain import FountainDecoder -> from hdmi_exfil.protocols.fountain import FountainDecoder
    ```

    **Strategy for each file:**

    1. **test_sequential.py** (~497 lines):
       - This is the heaviest migration. Tests use encode_frame/decode_frame as free functions.
       - Approach: Create a SequentialProtocol instance at module level: `_proto = SequentialProtocol()`
       - Replace `encode_frame(data, idx, total)` with `_proto.encode_frame(data, idx, total)`
       - Replace `decode_frame(sampled)` calls: The old decode_frame returns 4-tuple (idx, total, data, data_len). The new decode_frame returns FrameResult. Either:
         (a) Use `_proto.decode_frame_legacy(sampled)` if that method was created in 03-03, OR
         (b) Update each test to use FrameResult: `result = _proto.decode_frame(sampled); idx = result.frame_index`
         Prefer (b) for clean migration -- update tests to use FrameResult.
       - Replace `decode_frame_full(sampled)` calls: The old returns 5-tuple (ftype, idx, total, data, data_len). Use `result = _proto.decode_frame(sampled)` and extract fields.
       - Replace `sample_frame(frame)` with `sample_frame(frame, ROWS, COLS, BLOCK_SIZE)` (new sampler takes explicit params)
       - Replace `from common import *` with explicit: `from hdmi_exfil.config import BYTES_PER_FRAME, BLOCKS_PER_FRAME, ROWS, COLS, ...`
       - For route_frame: This was receiver.py's function. Either import from a compatibility location or re-implement the test inline. Since route_frame is a protocol-routing concern, consider if we need it in the new package. If not critical for tests, adapt the test to use the protocol directly.

    2. **test_fountain.py** (~373 lines):
       - Replace `from receiver_fountain import PRNG, FountainDecoder` with new imports
       - Update local constants to import from `hdmi_exfil.protocols.fountain` (PAYLOAD_SIZE, etc.)
       - The choose_indices helper defined in test can be replaced with `from hdmi_exfil.prng import choose_indices`
       - FountainDecoder usage stays the same (same API)

    3. **test_prng.py** (~170 lines):
       - Replace `from receiver_fountain import PRNG` with `from hdmi_exfil.prng import PRNG`
       - The choose_indices helper can be replaced with `from hdmi_exfil.prng import choose_indices`

    4. **test_properties.py** (~184 lines):
       - Replace sender/receiver/common imports with hdmi_exfil package imports
       - Use SequentialProtocol for encode/decode
       - Use new sampler with explicit params
       - FountainDecoder from new location

    5. **test_loopback.py** (~272 lines):
       - Replace sender/receiver/common imports with hdmi_exfil package imports
       - Use SequentialProtocol instance for encode/decode
       - Use new sampler with explicit params
