    1. Create `src/hdmi_exfil/cli/send.py` with `main()` function:
       - argparse: positional `input_path`, `--mode` (sequential/fountain, default sequential), `--fps` (default 240), `--redundancy` (default 1), `--screen` (default 0)
       - Workflow:
         a. `read_input(input_path)` -> (filename, file_data)
         b. `get_protocol(mode)` -> protocol instance
         c. `get_monitors()` -> select target monitor by screen index
         d. Create `FrameRenderer` with monitor offsets
         e. Display calibration frame (for sequential: create_calibration_frame from sender.py concept; for now a black frame), wait for keypress
         f. **Sequential mode**: encode_start_frame, then DATA frames in loop, then encode_end_frame. For each frame, call renderer.show with delay.
         g. **Fountain mode**: compute SHA-256, wrap metadata, slice into chunks, loop sending droplets (encode_frame with incrementing seed). Runs until user stops (Escape).
         h. Handle pause (Escape), resume (r), quit (q) -- same UX as sender.py
         i. Print timing stats at end
       - The CLI is a thin orchestrator -- no encoding logic, just wiring.

    2. Create `src/hdmi_exfil/cli/receive.py` with `main()` function:
       - argparse: positional `source`, `--output` (default "received_files"), `--mode` (auto/sequential/fountain, default auto)
       - Workflow:
         a. Create `CaptureSource(source, WIDTH, HEIGHT, fps=240)`
         b. Main loop: read frame, sample, attempt decode
         c. **Auto mode**: Try sequential decode first (check magic). If magic is fountain, switch to fountain mode.
         d. **Sequential mode**: Use TransferState FSM from receiver.py -- detect START, accumulate DATA, finalize on END, verify SHA-256
         e. **Fountain mode**: Initialize FountainDecoder on first valid packet, add droplets, check completion, parse metadata, verify SHA-256
         f. `write_output(file_content, filename, output_dir)` on completion
         g. Display debug frame with grid overlay (optional, cv2.imshow)
         h. Print progress and timing stats
       - The CLI is a thin orchestrator -- no decode logic, just wiring.

    IMPORTANT:
    - These CLI modules import ONLY from `hdmi_exfil.*` -- never from old flat modules.
    - Error handling: catch specific exceptions (FileNotFoundError, RuntimeError), print user-friendly messages.
    - The TransferState class should be imported or re-defined in cli/receive.py (simple state enum). Better: define it in `hdmi_exfil/protocols/sequential.py` and import it.
    - Add TransferState to sequential.py if not already there (it's currently in receiver.py).
  </action>

         const HEIGHT = {{CONST_HEIGHT}};
         const BLOCK_SIZE = {{CONST_BLOCK_SIZE}};
         const COLS = WIDTH / BLOCK_SIZE;
         const ROWS = HEIGHT / BLOCK_SIZE;
         const BITS_PER_FRAME = ROWS * COLS;

       - Keep all other HTML/CSS/JS exactly as-is.

    2. Create `web/build_sender.py`:
       - `build(output_path=None)` function:
         a. Locate constants.json inside the package: `importlib.resources.files("hdmi_exfil").joinpath("constants.json")`
         b. Load JSON
         c. Read `web/sender.template.html` (relative to this script's location: `Path(__file__).parent / "sender.template.html"`)
         d. Replace `{{CONST_WIDTH}}` with str(constants["width"]), `{{CONST_HEIGHT}}` with str(constants["height"]), etc.
           - Mapping: width -> CONST_WIDTH, height -> CONST_HEIGHT, block_size -> CONST_BLOCK_SIZE, fountain_magic -> CONST_FOUNTAIN_MAGIC
           - Convert fountain_magic to hex literal for JS: `0x` + hex(value)[2:].upper() -> "0xF0C0"
         e. Write to `output_path` or default: project root / "sender.html"
         f. Print confirmation message
       - `if __name__ == "__main__":` block calls build()
       - Also handle being run from any directory (use Path(__file__) for relative paths)

    3. Run `python web/build_sender.py` and verify the generated sender.html matches the current sender.html (same constant values).
