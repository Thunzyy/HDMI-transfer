**run_send() signature:**
```python
def run_send(
    input_path: str,
    mode: str = "sequential",
    profile: ResolutionProfile | None = None,
    renderer_type: str = "pygame",
    screen: int = 0,
    fps: int | None = None,
    redundancy: int = 1,
    fountain_redundancy: float | None = None,
) -> None:
```

**run_send() body:** Move ALL logic from `main()` after `args = parser.parse_args()` into `run_send()`. Specifically:
1. Profile resolution: `profile = profile or DEFAULT_PROFILE`
2. FPS resolution: `target_fps = fps if fps is not None else profile.target_fps`
3. File reading: `filename, file_data = read_input(input_path)`
4. Monitor detection and screen selection
5. Protocol instantiation: `protocol = get_protocol(mode, profile=profile)`
6. Renderer creation (pygame vs cv2 based on `renderer_type`)
7. Calibration frame display
8. Numba warmup (if fountain mode)
9. Dispatch to `_send_sequential()` or `_send_fountain()`

**main() becomes:**
```python
def main() -> None:
    parser = _build_parser()
    args = parser.parse_args()
    run_send(
        input_path=args.input_path,
        mode=args.mode,
        profile=PROFILES[args.profile] if args.profile else None,
        renderer_type=args.renderer,
        screen=args.screen,
        fps=args.fps,
        redundancy=args.redundancy,
        fountain_redundancy=args.fountain_redundancy,
    )
```

**CRITICAL:** Preserve ALL existing behavior exactly. The only change is structural -- logic moves from `main()` into `run_send()`, and `main()` calls it. No behavioral changes.
