  <behavior>
    RSD computation and degree sampling for LT fountain codes.

    Cases:
    - ideal_soliton(K=10) → [0, 0.1, 0.5, 0.1667, 0.0833, ...] (1-indexed, ρ(1)=1/K, ρ(d)=1/(d*(d-1)))
    - robust_soliton_cdf(K=100, c=0.1, delta=0.05) → monotonically increasing CDF from 0 to 1.0, length K+1
    - sample_degree(cdf, prng_with_seed_1) → deterministic degree (same seed always produces same degree)
    - choose_indices(seed=1, K=100) → frozenset of indices using RSD-sampled degree (deterministic)
    - FountainDecoder round-trip for K=10 data → recovers original data

    Constants:
    - DEFAULT_C = 0.1 (ripple tuning constant)
    - DEFAULT_DELTA = 0.05 (failure probability bound)
    - S = c * ln(K/delta) * sqrt(K) (expected ripple size)

    RSD formula:
    - Ideal: ρ(1) = 1/K, ρ(d) = 1/(d*(d-1)) for d=2..K
    - Tau: τ(d) = (S/K)*(1/d) for d=1..pivot-1, τ(pivot) = (S/K)*ln(S/δ), τ(d>pivot)=0
    - pivot = floor(K/S)
    - Normalize: μ(d) = (ρ(d) + τ(d)) / Z where Z = sum of all
    - CDF: cumulative sum of μ

    CRITICAL: The CDF must be pre-computed per (K, c, delta) tuple. Use functools.lru_cache.
    CRITICAL: For K=1, the distribution is trivially [0, 1.0] (always degree 1).
    CRITICAL: sample_degree must use prng.next_float() (SplitMix32) for determinism.
  </behavior>
