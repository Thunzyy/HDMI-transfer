  <files>src/hdmi_exfil/config.py</files>
  <action>
Add a frozen dataclass `ResolutionProfile` to config.py with the following fields:
- `name: str` -- profile identifier
- `width: int` -- frame width in pixels
- `height: int` -- frame height in pixels
- `block_size: int` -- pixel size of each encoding block
- `target_fps: int` -- target frames per second

Add computed properties:
- `cols -> int`: width // block_size
- `rows -> int`: height // block_size
- `blocks_per_frame -> int`: cols * rows
- `bits_per_frame -> int`: blocks_per_frame * 3 (3bpp)
- `seq_bytes_per_frame -> int`: (bits_per_frame // 8) - HEADER_SIZE
- `fount_header_size -> int`: 12 (FOUNT_HEADER_PRE_CRC + FOUNT_CRC_SIZE, hardcoded since fountain.py owns the exact value)
- `fount_bytes_per_frame -> int`: (bits_per_frame // 8) - fount_header_size

Note: `fount_header_size` is 12 bytes (magic(2) + seed(4) + K(2) + crc32(4)). This is duplicated from fountain.py's FOUNT_HEADER_SIZE to avoid circular import. Add a comment noting this.

Add PROFILES dict with three presets:
- "speed": ResolutionProfile("speed", 1920, 1080, 8, 240)
- "balanced": ResolutionProfile("balanced", 1920, 1080, 8, 60)
- "quality": ResolutionProfile("quality", 3840, 2160, 8, 30)

Add DEFAULT_PROFILE = PROFILES["speed"]

Keep ALL existing module-level constants unchanged. They already compute from constants.json and will continue to work. Do NOT alias them to DEFAULT_PROFILE -- they remain independent for backward compatibility. The profile system is additive, not a replacement.

Place the ResolutionProfile class and PROFILES dict AFTER the existing constants section but BEFORE the derived capacity values section.
  </action>

1. Add import: `from hdmi_exfil.config import ResolutionProfile, DEFAULT_PROFILE`
