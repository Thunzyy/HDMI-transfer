**Create `src/hdmi_exfil/cli/progress.py`:**

Implement `ProgressTracker` class with:
- `__init__(self, total_items: int, total_bytes: int)` -- stores totals, records start time via `time.perf_counter_ns()`, sets warmup period to 2 seconds
- `update(self, items: int = 1, bytes_count: int = 0)` -- increments counters
- `progress_pct` property -- returns `received / total_items` (0.0 if total_items is 0)
- `speed_bytes_per_sec` property -- returns `bytes_received / elapsed_seconds` (0.0 if elapsed < 0.001)
- `eta_seconds` property -- returns remaining_bytes / speed (inf if speed <= 0 or elapsed < warmup)
- `format_line(self, extra: str = "") -> str` -- returns formatted progress string:
  `"\rFrames: {received}/{total} ({pct:.1%}) | {speed:.1f} KB/s | ETA: {mm:ss}{extra}"`
  - During warmup (first 2 seconds): ETA shows "--:--"
  - After warmup: ETA shows "m:ss" format
- Static method `_format_eta(seconds: float) -> str` -- converts seconds to "m:ss" or "--:--" for inf

Only stdlib imports: `time`.

   - On each new DATA frame received, call `tracker.update(1, len(data))`

3. Update `_receive_fountain()`:
   - After first valid droplet (K and decoder created), create a ProgressTracker:
     ```python
     estimated_bytes = K * len(payload)
     tracker = ProgressTracker(K, estimated_bytes)
     ```
   - Simplest approach that preserves current behavior: keep `progress = len(decoder.chunks) / K` but add speed and ETA:
     ```python
     elapsed = time.perf_counter_ns() - start_ns
     if elapsed > 2e9:  # after 2s warmup
         speed = bytes_received / (elapsed / 1e9)
         remaining = (K - len(decoder.chunks)) * len(payload)
         eta = remaining / speed if speed > 0 else float('inf')
         eta_str = f" | {speed/1024:.1f} KB/s | ETA: {ProgressTracker._format_eta(eta)}"
     else:
         eta_str = " | ETA: --:--"
     sys.stdout.write(
         f"\rProgress: {progress:.1%} ({len(decoder.chunks)}/{K})"
         f"{eta_str}{capture_fps_str}"
     )
     ```
