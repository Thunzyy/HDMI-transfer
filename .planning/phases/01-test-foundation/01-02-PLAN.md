    Create `tests/test_fountain.py` with fountain-specific constants defined locally (NOT imported from common.py -- fountain uses different values):
    ```python
    FOUNTAIN_BYTES_PER_FRAME = 4050
    FOUNTAIN_HEADER_LEN = 6
    FOUNTAIN_PAYLOAD_SIZE = 4044  # FOUNTAIN_BYTES_PER_FRAME - FOUNTAIN_HEADER_LEN
    ```

    Implement a `build_droplet(seed, K, chunks)` helper that mirrors the JS encoder logic:
    ```python
    def choose_indices(seed, K):
        prng = PRNG(seed)
        degree = 1
        r = prng.next_float()
        if r < 0.1: degree = 1
        elif r < 0.6: degree = 2
        else: degree = int(prng.next_float() * min(K, 20)) + 1
        indices = set()
        while len(indices) < degree:
            indices.add(prng.next() % K)
        return indices

    def build_droplet(seed, K, chunks):
        indices = choose_indices(seed, K)
        payload = bytearray(FOUNTAIN_PAYLOAD_SIZE)
        for idx in indices:
            for i in range(FOUNTAIN_PAYLOAD_SIZE):
                payload[i] ^= chunks[idx][i]
        return payload
    ```

    Implement a `prepare_chunks(data)` helper that splits data into FOUNTAIN_PAYLOAD_SIZE chunks, zero-padded:
    ```python
    def prepare_chunks(data):
        K = -(-len(data) // FOUNTAIN_PAYLOAD_SIZE)  # ceil division
        chunks = []
        for i in range(K):
            chunk = bytearray(FOUNTAIN_PAYLOAD_SIZE)
            start = i * FOUNTAIN_PAYLOAD_SIZE
            end = min(start + FOUNTAIN_PAYLOAD_SIZE, len(data))
            chunk[:end-start] = data[start:end]
            chunks.append(chunk)
        return K, chunks
    ```

    Tests:

    1. `test_fountain_single_chunk` -- Data fits in 1 chunk (K=1). Build droplets with seeds 1, 2, 3, ..., feed to FountainDecoder. Assert `is_complete()` after at most 3 droplets. Recover data, assert byte-for-byte match (trimmed to original length).

    2. `test_fountain_small_data` -- 100 bytes of random data. K will be 1. Verify recovery.

    3. `test_fountain_multi_chunk` -- Data spanning exactly 3 chunks (K=3). Use `os.urandom(FOUNTAIN_PAYLOAD_SIZE * 3)`. Build droplets starting from seed=1, feed to decoder one at a time until `is_complete()`. Assert completion within K*5 droplets. Verify byte-for-byte match.

    4. `test_fountain_larger_data` -- Data spanning 10 chunks (K=10). Use `os.urandom(FOUNTAIN_PAYLOAD_SIZE * 10)`. Allow up to K*10 droplets (fountain overhead is variable). Verify recovery.

    5. `test_fountain_partial_last_chunk` -- Data that does NOT evenly divide into FOUNTAIN_PAYLOAD_SIZE. E.g., `os.urandom(FOUNTAIN_PAYLOAD_SIZE * 2 + 500)`. K=3, but last chunk is partially filled. Verify recovery of exact original data (trimmed).

    6. `test_fountain_known_data` -- Use non-random data: `b'\xAA' * 10000`. Verify recovery. This catches XOR bugs that random data might mask.

    7. `test_fountain_decoder_idempotent_droplets` -- Feed the same droplet (same seed) twice. Verify decoder does not crash and still completes correctly.

    8. `test_fountain_overhead_reasonable` -- For K=10, measure how many droplets are needed to complete. Run 5 times with different data. Assert average overhead is under 5x (i.e., fewer than 50 droplets needed on average for 10 chunks). This is a soft sanity check, not a hard performance test.
