<objective>
Replace all cv2.resize calls in protocol encoding and frame sampling with pure numpy equivalents so these modules can live in core/ without an OpenCV dependency.

Purpose: STRUCT-06 is the critical blocker for the monorepo split. Both SequentialProtocol.encode_frame() and FountainProtocol.encode_frame() call cv2.resize for nearest-neighbor upscale, and capture/sampler.py uses cv2.resize for frame dimension mismatch. These must use np.repeat (upscale) and numpy indexing (downscale) instead.

Output: Three files modified with zero cv2 imports, all tests still passing.
</objective>
