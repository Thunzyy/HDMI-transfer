  <name>Task 1: Upgrade fountain.py to 3bpp encoding</name>
  <files>src/hdmi_exfil/protocols/fountain.py</files>
  <action>
    1. Update capacity constants at module level. Keep the old 1bpp constants (commented out or removed) and add new 3bpp constants:
       ```python
       # 3bpp: 3 bits per block (RGB binary), same as sequential protocol
       FOUNTAIN_BYTES_PER_FRAME: int = (config.ROWS * config.COLS * 3) // 8  # 12150
       PAYLOAD_SIZE: int = FOUNTAIN_BYTES_PER_FRAME - FOUNT_HEADER_SIZE  # 12138
       ```
       The old value was `(config.ROWS * config.COLS) // 8` = 4050 (1bpp). The new value is `(config.ROWS * config.COLS * 3) // 8` = 12150 (3bpp). PAYLOAD_SIZE goes from 4038 to 12138.

    2. Update `FountainProtocol.encode_frame()` to use 3bpp encoding (copy the pattern from SequentialProtocol.encode_frame):
       - Replace the 1bpp bit->RGB mapping (black/white) with 3bpp:
         ```python
         byte_arr = np.frombuffer(frame_bytes, dtype=np.uint8)
         bits = np.unpackbits(byte_arr)
         total_bits_needed = config.BLOCKS_PER_FRAME * 3
         if len(bits) < total_bits_needed:
             bits = np.pad(bits, (0, total_bits_needed - len(bits)), 'constant')
         pixel_bits = bits[:total_bits_needed].reshape((config.BLOCKS_PER_FRAME, 3))
         pixel_values = pixel_bits * 255
         blocks_grid = pixel_values.reshape((config.ROWS, config.COLS, 3)).astype(np.uint8)
         ```
       - Keep the cv2.resize at the end (same as before).

    3. Update `FountainProtocol.decode_frame()` to use 3bpp decoding (copy the pattern from SequentialProtocol.decode_frame):
       - Replace the 1bpp green-channel-only threshold with 3-channel threshold:
         ```python
         flat = sampled_grid.reshape(-1, 3)
         bits = (flat > 128).astype(np.uint8)
         flat_bits = bits.reshape(-1)
         raw_bytes = np.packbits(flat_bits).tobytes()
         ```
       - The old code was: `bits = (flat[:, 1] > 128).astype(np.uint8)` (green channel only, 1bpp).
       - The new code thresholds all 3 channels and packs 3 bits per block (identical to sequential).

    4. Update the docstrings: class docstring, encode_frame, decode_frame to reflect 3bpp. Update the `__init__` to use the new constants.

    5. Do NOT modify FountainDecoder -- it operates on raw bytes (payload), not pixels. The 3bpp change only affects encode_frame/decode_frame visual representation.
  </action>
